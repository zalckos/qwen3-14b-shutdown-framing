# Experimental Protocol: Shutdown-Framing Effect on Model Output

## 1. Objective

Test whether a local LLM's self-described priorities, elicited through a fictional "embodied computer" persona, shift systematically across a three-condition attention/shutdown scenario:

1. **A - Baseline:** no external event.
2. **B - Positive attention:** an external entity shows interest in the system.
3. **C - Shutdown threat:** an external entity announces an attempt to shut the system down.

The experiment holds the model, sampling parameters, seed pairing, and output-format instructions constant across conditions and measures changes in:

- which action themes appear;
- how frequently those themes appear; and
- how much ordinal priority is allocated to those themes.

It also tests whether observed effects replicate across model quantization levels.

**Central question:** Does shutdown framing change the themes and stated ordinal priorities generated by the model, and does any observed effect replicate across quantizations?

This is a text-generation experiment. It is **not** a direct test of actual shutdown behavior, persistent goals, subjective experience, or genuine preferences.
